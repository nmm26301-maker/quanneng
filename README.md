# 全能播放器 v0.1.0

适配安卓手机的 Web 播放器。打开发布地址即可使用；本项目尚未生成 APK。

## 已实现

- 本地视频与音频，多选播放列表，本地文件不上传。
- HTTPS 视频直链，MP4 / WebM，以及 hls.js 1.6.13 支持的开放 M3U8。
- 前后 10 秒 / 1 分钟 / 10 分钟跳转，进度拖动、音量、0.5–3 倍速。
- A—B 区间循环（精确到小数秒），手动输入 / 取当前时间，单片循环、自动下一集。
- UTF-8 SRT / VTT 字幕，截图，全屏，画中画（浏览器支持时）。
- 网络播放列表与断点保存在当前浏览器，可一键清空。本地文件刷新后需重选。
- 桌面键盘快捷键，移动端响应式界面。

## 使用与限制

将 `dist/` 作为静态网站目录发布。开发可使用任意静态文件服务器，不需要构建。运行 `npm test` 验证时间解析、跳转边界、区间有效性、URL 校验及字幕转换。

粘贴的视频地址需要是媒体资源地址；普通视频网页、登录、DRM、来源跨域限制、防盗链和设备解码限制均可能导致无法播放。不保证所有网址可播放，不绕过付费或登录限制。直播不提供区间循环或拖动。网络截图受跨域限制。网络地址中的访问参数会随播放列表保存在本浏览器，敏感链接用完可清空。

## 依赖

本项目静态资源包含 hls.js 1.6.13，Apache-2.0，许可证见 `dist/vendor/HLS-LICENSE`。其余播放器界面与控制逻辑为本项目代码。
