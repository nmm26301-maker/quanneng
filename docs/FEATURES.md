## 构建及安全范围

当前版本：versionCode 11 / versionName 0.3.2；手机包 arm64-v8a。当前测试签名与旧版不同，原密钥恢复前不提供覆盖升级承诺。

为 DLNA 和常见家用 NAS 的 HTTP 控制端点启用 Android 明文网络能力。所有新增网络入口执行 `NetworkPolicy`，公网地址仍要求 HTTPS；HTTP 仅接受 10/8、172.16/12、192.168/16 数字 IP，不接受公网 HTTP、回环、链路本地、URL 内账号密码。NAS 认证媒体数据源只允许选定源，拒绝跨源和重定向。WebDAV / SOAP 请求由固定版本 OkHttp 处理，XML 禁用 DTD/外部实体并限制响应大小。

加密库是应用本地文件保护功能，不宣称能在已 root、已攻破系统或运行时被注入的设备上防止窃取。原文件及用户导出的明文由用户自行管理。

## v0.3.1 新增与修复

- 本地普通视频可从投屏页或接力页选择，或从播放器把当前视频带入；准备后生成一次性随机链接。临时副本只允许局域网读取，不开放目录、上传或任意文件。
- 本地共享支持 HTTP GET、HEAD、单区间 Range、后缀范围及拖动。链接 30 分钟后拒绝访问；前台服务可后台继续，停止共享或“立即锁定”会撤销会话并删除副本。退出最近任务也会停止。准备期间请保持全能在前台。保险箱视频不允许共享。
- DLNA 请求补上视频 DIDL 元数据；跨设备接力可传递本地共享链接与进度，接收设备需同一 Wi-Fi。不同网络仍需已有双方可访问的网址。
- 原生播放自动保存进度；重新选择同一视频时继续。字幕选用按媒体保存，字号和偏移调整返回后生效；异步字幕结果不能覆盖已切换的视频。
- 下载和转换任务显示来源/名称，保存结果使用可辨认文件名；队列采用独立递增顺序，避免同毫秒入队随机排位。
- 工具参数在打开系统选择器前固定并保存，取消不会启动任务；不使用时间参数的工具不受旧的错误时间输入影响。表单错误和保存状态不会被半秒刷新覆盖。
- 保险箱在解锁后读取经过认证的加密文件名称，磁盘不增加明文名称索引；防止功能页重复提交同一操作。
- 修正字幕偏移极端整数及有前导零的私网地址边界。

新增验证：MediaRangeCheck 主机端点测试与 ShareSmoke Android 集成测试，覆盖真实共享字节、Range/HEAD、错误令牌、禁止上传、后台、停止撤销、接收分享后原生解码、工具状态和错误反馈。实机电视/NAS 兼容性仍需验收。

## v0.3.2 横屏与解锁改进

- 原生横屏控制区改为底部透明浮层，播放、四个跳转、步长、倍速和全屏在同一操作行；48dp 触控范围，固定预留系统导航/手势区与屏幕缺口，系统栏显隐不再推动按钮。
- 进度条相对拖动以整秒预览（约 6dp/秒），上移 32dp 后慢调（18dp/秒），松手定位；取消或多指触碰不提交。点按轨道仍可快速跳转，触摸探索保留原生 SeekBar。
- 系统设有锁屏验证时，首次直接调用 Android 指纹/锁屏 PIN、图案或密码，无需另建全能密码。Android 9+ 优先 BiometricPrompt，较早版本和不可用生物识别回退系统凭据页。已有私人密码可备用；没有系统锁屏时才使用原有密码设置。
- 解锁后页面切换、旋转、选文件及短暂切到后台不重复验证；后台 5 分钟、屏幕关闭、手动锁定、退出或进程重启会再次验证。验证取消、过期回调均不解锁。密码修改仍验证旧私人密码。
- 本次原签名私钥所在旧临时目录已不存在，未找到全能签名恢复备份。源码和 CI 不含私钥；当前本地构建使用隔离测试密钥，不能声称可覆盖旧版。禁止为解决签名冲突建议卸载旧版，尤其保险箱数据依赖设备原密钥。
- 新增真实系统 PIN 仪器测试与横屏单手按秒拖动、慢调、取消测试。结果以本版本 CI 记录为准；指纹仍需真实设备实测。

后台 5 分钟免重复验证不延长保险箱明文缓存的生命周期：进入后台仍立即清理，后台解密请求被拒绝，解密提交与清理互斥。ShareSmoke 增加对应回归。

- 防误触锁定：竖屏操作行 / 横屏顶部新增锁图标；竖屏点击会进入全屏并锁定播放器触控。视频继续播放，进度、按钮、画面手势和应用返回均不响应误触，仅保留透明“长按解锁”键。单击解锁键只显示提示，长按解除；不触发密码验证，系统音量键和系统切换应用保留。加载失败时自动解除，便于重试。

- 横屏右上角显示本机当前时间，遵循手机 12/24 小时格式；与播放控制一起显示、自动隐藏，防误触锁定时隐藏，不常驻画面。
