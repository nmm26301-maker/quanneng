入口：底部「功能中心」。原播放器、六平台入口和收藏继续保留。

| 播放诊断 | 检查当前网络、HTTP 状态/耗时/MIME、设备编码支持，并可分享报告 | 报告隐藏路径及参数；无 Cookie 的探测不能代替真实授权播放 |

| 视频工具箱 | FFmpeg 裁剪片段、提取 M4A、压缩 MP4、JPG 截图、无声 MP4、兼容转换 | 只操作系统选择器授权的普通媒体；起止填写秒数；结果需另存到手机 |

## 验证

- 前端：`npm ci --prefix frontend && npm test --prefix frontend && npm run build --prefix frontend`。
- 主机协议测试：`android/tests/FeaturePolicyCheck.java`，覆盖 URL 边界、同源、字幕时间、接力格式和禁用 XML DTD。
- Android：`FeatureSmoke` 在 CI/模拟器测试真实 Keystore 文件往返、密文篡改/截断、持久化队列中断恢复、字幕、接力、本机模拟 DLNA SOAP / WebDAV 请求及 8 个新页面。
- 原有 SecuritySmoke / PlaybackSmoke / BrowserSmoke / TransferSmoke 保留。
- 真实电视型号、真实 NAS 提供器和不同安卓手机的兼容性需要实机验收；模拟协议测试不代表所有设备均兼容。

## 构建及安全范围

版本：versionCode 9 / versionName 0.3.0；手机包 arm64-v8a。原签名可继续覆盖升级，不清空原应用数据。

为 DLNA 和常见家用 NAS 的 HTTP 控制端点启用 Android 明文网络能力。所有新增网络入口执行 `NetworkPolicy`，公网地址仍要求 HTTPS；HTTP 仅接受 10/8、172.16/12、192.168/16 数字 IP，不接受公网 HTTP、回环、链路本地、URL 内账号密码。NAS 认证媒体数据源只允许选定源，拒绝跨源和重定向。WebDAV / SOAP 请求由固定版本 OkHttp 处理，XML 禁用 DTD/外部实体并限制响应大小。

加密库是应用本地文件保护功能，不宣称能在已 root、已攻破系统或运行时被注入的设备上防止窃取。原文件及用户导出的明文由用户自行管理。
