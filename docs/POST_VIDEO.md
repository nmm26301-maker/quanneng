# 帖子视频入口

从 X 等应用把帖子链接分享给“全能新版”，打开的是原帖网页。网页内视频若公开提供可独立播放的媒体地址，可在浏览器页面选择“转到全能播放”。若网页播放器未暴露地址，点“帖子视频：保存后播放”，下载与转换页会预填当前帖子链接；点“下载到私人空间”，完成后在已完成列表点“播放”。

仅处理用户分享或主动打开的 HTTPS 链接。普通网页点击和平台后台缓存不作为视频来源。站点需被现有 yt-dlp 组件支持；登录、过期地址、受保护视频和 DRM 内容可能无法使用。不会从其他应用读取私有缓存或账号。这个入口不会自动处理动态信息流里的每一条帖子。

本改动应合入最新播放器源码后构建新版本，并在 Android 真机上验收 X 帖子分享、网页视频转接以及下载完成后的本地播放。

v0.4.5 中，网页媒体的可转接结果仅在点击原生“识别当前视频”后记录；检测不会自动打开播放器。识别多条时按可播放优先级列出供手动选择。受保护媒体继续在原网页观看。
